مجموع ارائه‌دهندگان: **359**. تفکیک دسته‌بندی‌ها را در پایین ببینید.

## دستهبندیها

- **رایگان** — سطح رایگان با کلید API (پیکربندی از طریق داشبورد)
- **بدون احراز هویت** — نقاط پایانی عمومی که اصلاً به کلید یا ورود به حساب نیاز ندارند
- **OAuth** — فرایند ورود توسط OmniRoute مدیریت میشود و به کلید API نیازی نیست
- **کوکی وب** — برنامهٔ وب ارائهدهنده را با استفاده از احراز هویت مبتنی بر کوکی دربر میگیرد
- **کلید API** — ارائهدهندهٔ پولی که از طریق کلید API پیکربندی میشود (ممکن است اعتبار رایگان ارائه شود)
- **محلی** — روی دستگاه کاربر اجرا میشود (Ollama، LM Studio، vLLM و غیره)
- **جستوجو** — ارائهدهندگان جستوجوی وب
- **صوت** — ارائهدهندگان صرفاً صوتی (TTS/STT)
- **پروکسی بالادستی** — ارائهدهندگانی که درخواستها را به ارائهدهندگان دیگر پروکسی میکنند
- **عامل ابری** — عاملهای کدنویسی با اجرای طولانیمدت (Codex Cloud، Devin، Jules)
- **سیستمی** — ارائهدهندگان داخلی OmniRoute (loopback و غیره)

برچسبهای تکمیلی: `image`، `video`، `aggregator`، `enterprise`، `embed/rerank`، `self-hosted`.

`فراخوانی ابزار` (در مواردی که نمایش داده شده است): `native` — API واقعی فراخوانی تابع؛ `emulated` — آرایهٔ `tools` از طریق `webTools.ts` بهصورت پرامپتی شبیهسازی میشود (بلوکهای `<tool>{...}</tool>` با regex تجزیه میشوند)؛ `none` — در حال حاضر `tools` بدون هیچ هشداری نادیده گرفته میشود. #7286 را ببینید.

برای فعالسازی، پیکربندی و آزمایش هر ارائهدهنده، از داشبورد در `/dashboard/providers` استفاده کنید.
