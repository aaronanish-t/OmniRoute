## श्रेणियाँ

- **निःशुल्क** — API कुंजी के साथ निःशुल्क स्तर (डैशबोर्ड के माध्यम से कॉन्फ़िगर किया जाता है)
- **बिना प्रमाणीकरण** — सार्वजनिक एंडपॉइंट, जिनके लिए किसी कुंजी या साइन-इन की आवश्यकता नहीं होती
- **OAuth** — OmniRoute द्वारा प्रबंधित साइन-इन प्रवाह, API कुंजी की आवश्यकता नहीं
- **वेब कुकी** — कुकी प्रमाणीकरण के माध्यम से प्रदाता के वेब ऐप को रैप करता है
- **API कुंजी** — API कुंजी के माध्यम से कॉन्फ़िगर किया गया सशुल्क प्रदाता (निःशुल्क क्रेडिट लागू हो सकते हैं)
- **लोकल** — उपयोगकर्ता की मशीन पर चलता है (Ollama, LM Studio, vLLM, आदि)
- **खोज** — वेब खोज प्रदाता
- **ऑडियो** — केवल-ऑडियो प्रदाता (TTS/STT)
- **अपस्ट्रीम प्रॉक्सी** — वे प्रदाता जो अन्य प्रदाताओं को प्रॉक्सी करते हैं
- **क्लाउड एजेंट** — लंबे समय तक चलने वाले कोडिंग एजेंट (Codex Cloud, Devin, Jules)
- **सिस्टम** — OmniRoute के आंतरिक प्रदाता (लूपबैक, आदि)

अतिरिक्त टैग: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`।

`टूल कॉलिंग` (जहाँ दिखाया गया है): `native` — वास्तविक फ़ंक्शन-कॉलिंग API; `emulated` — `tools` ऐरे को `webTools.ts` के माध्यम से प्रॉम्प्ट-अनुकरण किया जाता है (रेगेक्स द्वारा पार्स किए गए `<tool>{...}</tool>` ब्लॉक); `none` — `tools` को वर्तमान में बिना किसी सूचना के हटा दिया जाता है। #7286 देखें।

प्रत्येक प्रदाता को सक्षम, कॉन्फ़िगर और परीक्षण करने के लिए `/dashboard/providers` पर डैशबोर्ड का उपयोग करें।
