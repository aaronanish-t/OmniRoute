## వర్గాలు

- **Free** — API కీతో ఉచిత శ్రేణి (డాష్బోర్డ్ ద్వారా కాన్ఫిగర్ చేయబడింది)
- **No-auth** — ఎటువంటి కీ లేదా సైన్-ఇన్ అవసరం లేని పబ్లిక్ ఎండ్పాయింట్లు
- **OAuth** — OmniRoute ద్వారా నిర్వహించబడే సైన్-ఇన్ ఫ్లో, API కీ అవసరం లేదు
- **Web cookie** — కుకీ ప్రమాణీకరణ ద్వారా ప్రొవైడర్ యొక్క వెబ్ యాప్ను చుట్టి ఉంటుంది
- **API key** — API కీ ద్వారా కాన్ఫిగర్ చేయబడిన చెల్లింపు ప్రొవైడర్ (ఉచిత క్రెడిట్లు వర్తించవచ్చు)
- **Local** — వినియోగదారు మెషీన్లో నడుస్తుంది (Ollama, LM Studio, vLLM, మొదలైనవి)
- **Search** — వెబ్ శోధన ప్రొవైడర్లు
- **Audio** — ఆడియో-మాత్రమే ప్రొవైడర్లు (TTS/STT)
- **Upstream proxy** — ఇతర ప్రొవైడర్లకు ప్రాక్సీ చేసే ప్రొవైడర్లు
- **Cloud agent** — దీర్ఘకాలిక కోడింగ్ ఏజెంట్లు (Codex Cloud, Devin, Jules)
- **System** — OmniRoute-అంతర్గత ప్రొవైడర్లు (loopback, మొదలైనవి)

అదనపు ట్యాగ్లు: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (చూపిన చోట): `native` — నిజమైన ఫంక్షన్-కాలింగ్ API; `emulated` — `tools` శ్రేణి `webTools.ts` ద్వారా ప్రాంప్ట్-ఎమ్యులేట్ చేయబడింది (regex-parsed `<tool>{...}</tool>` బ్లాక్లు); `none` — `tools` ప్రస్తుతం నిశ్శబ్దంగా వదిలివేయబడింది. #7286 చూడండి.

ప్రతి ప్రొవైడర్ను ఎనేబుల్ చేయడానికి, కాన్ఫిగర్ చేయడానికి మరియు పరీక్షించడానికి `/dashboard/providers` వద్ద ఉన్న డాష్బోర్డ్ను ఉపయోగించండి.
