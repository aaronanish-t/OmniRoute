## Categorie

- **Gratuito** — piano gratuito con chiave API (configurata tramite la dashboard)
- **Nessuna autenticazione** — endpoint pubblici che non richiedono alcuna chiave né accesso
- **OAuth** — flusso di accesso gestito da OmniRoute, senza necessità di una chiave API
- **Cookie web** — integra l'app web del provider tramite autenticazione con cookie
- **Chiave API** — provider a pagamento configurato tramite chiave API (potrebbero essere disponibili crediti gratuiti)
- **Locale** — viene eseguito sul computer dell'utente (Ollama, LM Studio, vLLM, ecc.)
- **Ricerca** — provider di ricerca sul web
- **Audio** — provider esclusivamente audio (TTS/STT)
- **Proxy upstream** — provider che fungono da proxy verso altri provider
- **Agente cloud** — agenti di programmazione a lunga esecuzione (Codex Cloud, Devin, Jules)
- **Sistema** — provider interni di OmniRoute (loopback, ecc.)

Tag aggiuntivi: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Chiamata di strumenti` (dove indicata): `native` — vera API di chiamata delle funzioni; `emulated` — l'array `tools` viene emulato tramite prompt mediante `webTools.ts` (blocchi `<tool>{...}</tool>` analizzati con espressioni regolari); `none` — al momento `tools` viene ignorato senza alcun avviso. Vedi #7286.

Usa la dashboard all'indirizzo `/dashboard/providers` per abilitare, configurare e testare ciascun provider.
