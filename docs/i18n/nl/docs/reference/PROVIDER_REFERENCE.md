## Categorieën

- **Gratis** — gratis abonnement met API-sleutel (geconfigureerd via het dashboard)
- **Zonder authenticatie** — openbare endpoints waarvoor helemaal geen sleutel of aanmelding vereist is
- **OAuth** — aanmeldingsproces afgehandeld door OmniRoute, geen API-sleutel nodig
- **Webcookie** — ontsluit de webapp van de provider via cookie-authenticatie
- **API-sleutel** — betaalde provider die via een API-sleutel wordt geconfigureerd (mogelijk zijn gratis tegoeden beschikbaar)
- **Lokaal** — wordt uitgevoerd op de computer van de gebruiker (Ollama, LM Studio, vLLM, enz.)
- **Zoeken** — providers voor zoeken op het web
- **Audio** — providers uitsluitend voor audio (TTS/STT)
- **Upstreamproxy** — providers die als proxy voor andere providers fungeren
- **Cloudagent** — langlopende codeeragents (Codex Cloud, Devin, Jules)
- **Systeem** — interne providers van OmniRoute (loopback, enz.)

Aanvullende tags: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (waar weergegeven): `native` — echte API voor functieaanroepen; `emulated` — de `tools`-array wordt via `webTools.ts` in de prompt geëmuleerd (met regex geparseerde `<tool>{...}</tool>`-blokken); `none` — `tools` wordt momenteel stilzwijgend weggelaten. Zie #7286.

Gebruik het dashboard op `/dashboard/providers` om elke provider in te schakelen, te configureren en te testen.
