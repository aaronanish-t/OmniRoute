## კატეგორიები

- **უფასო** — უფასო დონე API გასაღებით (კონფიგურირდება მართვის პანელიდან)
- **ავტორიზაციის გარეშე** — საჯარო საბოლოო წერტილები, რომლებსაც საერთოდ არ სჭირდება გასაღები ან სისტემაში შესვლა
- **OAuth** — სისტემაში შესვლის პროცესს OmniRoute მართავს, API გასაღები საჭირო არ არის
- **ვებ-ქუქი** — პროვაიდერის ვებაპლიკაციას ქუქიზე დაფუძნებული ავტორიზაციის საშუალებით იყენებს
- **API გასაღები** — ფასიანი პროვაიდერი, რომელიც API გასაღებით კონფიგურირდება (შესაძლოა, უფასო კრედიტები მოქმედებდეს)
- **ლოკალური** — მუშაობს მომხმარებლის კომპიუტერზე (Ollama, LM Studio, vLLM და ა.შ.)
- **ძიება** — ვებში ძიების პროვაიდერები
- **აუდიო** — მხოლოდ აუდიოს პროვაიდერები (TTS/STT)
- **ზედა დონის პროქსი** — პროვაიდერები, რომლებიც სხვა პროვაიდერებთან პროქსირებას ახდენენ
- **ღრუბლოვანი აგენტი** — ხანგრძლივად მომუშავე პროგრამირების აგენტები (Codex Cloud, Devin, Jules)
- **სისტემური** — OmniRoute-ის შიდა პროვაიდერები (loopback და ა.შ.)

დამატებითი ტეგები: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (სადაც ნაჩვენებია): `native` — ფუნქციების გამოძახების რეალური API; `emulated` — `tools` მასივის ემულაცია ხდება მოთხოვნის ტექსტის მეშვეობით, `webTools.ts`-ის გამოყენებით (რეგულარული გამოსახულებით დამუშავებული `<tool>{...}</tool>` ბლოკები); `none` — ამჟამად `tools` უხმოდ გამოიტოვება. იხილეთ #7286.

თითოეული პროვაიდერის ჩასართავად, დასაკონფიგურირებლად და შესამოწმებლად გამოიყენეთ მართვის პანელი მისამართზე `/dashboard/providers`.
